# Tic-Tac-Toe Mini Game

---

## Project Overview

This project is a rebuild of the Tic-Tac-Toe game based on the official React documentation.  
It serves as a learning exercise to understand the fundamentals of **React components**, **state management**, and **lifting state up**.
